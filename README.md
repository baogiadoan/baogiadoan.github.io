# Dr. Bao Gia Doan — academic website

Source for [www.baodoan.net](https://www.baodoan.net), built with Jekyll and the
[al-folio](https://github.com/alshedivat/al-folio) academic website starter.

## Writing a blog post

Add a Markdown file to `_posts` named `YYYY-MM-DD-title.md` with front matter like:

```yaml
---
layout: post
title: Your post title
date: 2026-08-12
description: A one-sentence summary.
tags: [trustworthy-ai]
categories: [research]
---
```

The post will appear automatically under `/blog/`.
